Trust is a ceiling, not a floor. An agent may ask and wait on any call it judges risky, whatever its score. The server never makes it act on trust.

How it adds up

StartEvery model starts at 50, worth about 6 decisions, so a few kept picks cannot carry it to 70.
ScoreThe share of weight that is for it, as a whole number out of 100.
Recent firstA decision 20 decisions old counts half as much as the latest one.
KindsDefaults, API / design, Scope / split, Visual / UI and Approval each get their own score; the band uses the overall one.
ScopesA decision inside a declared folder moves that folder’s score, not the project’s.
